# 场景、材质与动作实现报告

日期：2026-11-18。冒烟测试和地道封闭测试通过。碰撞、地道路线和门洞坐标没有移动。

## 审查后的分配

整座院子或整条地道如果换成一个生成模型，门洞、枪眼和隔板会对不齐，人也可能被模型挡住。所以没有整栋替换。

| 内容 | 做法 | 原因 |
|---|---|---|
| 房屋墙 | 生成的夯土墙段，按原有墙段拉伸 | 门洞仍是墙段之间的空档 |
| 屋顶 | 生成的灰瓦，铺在原屋顶上，檐高约 0.7 米 | 屋面要有瓦垄，不能只是一块平板 |
| 地面、地道壁 | 程序：细分网格后沿法线做坑洼 | 走路的碰撞盒保持平整 |
| 田地草、远树冠 | 程序：草叶随风，树冠只摆顶部 | Compatibility 渲染器能做的顶点动画 |
| 天空、雾、日光阴影、油灯闪烁 | 程序 | 不需要模型 |
| 涌水 | 程序：一条连续浑水带，水头跟进度走 | 生成的一滩水对不齐井下路线 |
| 侦察树 | 树干保留原窄缝碰撞，外表改树皮；树冠用生成的国槐枝叶，底坐在约 2.75 米 | 窄缝必须留在东面眼高处 |
| 院树 | 同一棵生成树，底改到地面 | 原先挂在树干方块中心，人看是悬空 |
| 翻板、隔板、翻口、翻眼 | 生成的旧木板换掉方块，原来的转动和开关还在 | 交互不能绑死在模型上 |
| 第三名农妇 | 单独生成一身灰袄、蓝围裙 | 原先和年轻村民共用身体 |
| 骨骼 | 三次绑骨都失败 | 现有模型双臂贴身，不是 A 字或 T 字站姿 |

这一批预估 43 积分。三次失败绑骨按 45 记入账本，等用量回执确认是否真的扣了。加上此前约 210，仍在 2800 的工作额度里。

## 空间

院内道具原来都以碰撞盒中心为脚底，所以会悬在半空。现已改成脚底对齐碰撞盒底面。院树单独把脚底放到世界高度 0。钟仍在树冠高度。

屋里的炕靠北墙，八仙桌在炕前，柜子在桌侧。东屋炕、西屋案板和风箱、南屋粮囤都在各自房子的墙内。没有把家具挪出房子。

地道里，翻板没有挡路碰撞。隔板敞开时向上翻开，关上才挡人和挡水。翻口默认挡住死道，报信直道仍通。翻眼挡住村民暗室，打开后才能进。这些阻挡是机关本身，不是摆放错误。

## 人物

我方现在是四套外形：甲的靛蓝短褂、乙的灰蓝短褂、年长村民的褐袄、年轻村民的靛蓝、第三名农妇的灰袄和蓝围裙。敌军仍是一套黄褐军衣。

没有骨骼。每个人有缓慢的换气，以及隔几秒一次的转头，转完会回到正前方，不会一直左右摇。村民会偶尔停在“干活”的阶段，但因为没有对应骨骼，这一阶段现在只是时间上的间隔。面部没有眼皮和嘴的骨骼，所以没有眨眼。

布料材质把金属度和高光压低，粗糙度提到 0.9 以上，让粗布不发塑料光。

## 还没做到的

- 侦察树的树干仍是方柱轮廓，只是有了树皮凹凸和上面的枝叶。圆树干会盖住东面窄缝。
- 墙段是按每段墙拉伸的，长墙上的夯纹会被拉宽。
- 第三名农妇的提示词把“髻”写成了“髦”，进游戏后要看头发是否怪。
- 绑骨要等重新生成 A 字站姿的身体，才能接走路、交谈和点头。现有这批贴臂模型平台不收。
