## 实现决策（低成本可逆）

| 决策 | 理由 |
|------|------|
| Compatibility 渲染 | 兼顾 Windows / WebGL2 / 移动 |
| 灰盒程序化搭建 `GrayboxBuilder` | 最快验证空间关系与玩法 |
| 敌军地面移动暂用直接趋近，保留 NavigationAgent3D 挂点 | Demo 院落尺度足够；后续可烤导航网格 |
| 绳索垂降：短延迟 + 传送落点 | 避免通用攀爬/绳索物理阻塞 P0 |
| 步枪备弹：弹仓 8 发，空仓不可补 | 符合“备弹 8 发”的 Demo 简化 |
| 未消耗 Aholo | 先闭环后资产 |
| 身上只有弹仓，打光后到地道弹药暗室补充 | 用户 2026-11-16 要求。每次最多 4 发，暗室库存 16，须离开后再取 |
| 地面与地道分层约 5 米 | 上一版灰盒叠在一起，人和洞口都看不见 |
| 2026-11-16 用户俯视图与动线 | 四面房子围院；院内树、钟、锅、井；东屋为地道出口；墙外树下是瞭望口；敌军从东边持续向村里走。玩家先从瞭望口钻地道回东屋，再拉钟。钟响后村民隐蔽，战友自己上阵地。G 近距离喊话，15 米内敌军可能听见 |
| 地道是封闭的挖道，入口隐蔽 | 用户审查：不能从地道掉出去。地面不挖敞口。入口藏在树洞、锅台、水井、东屋，用交互进入。以后的 3D 模型也要把洞口藏在这些物体里，不能做成露天竖井 |
| 开场并列两个模式 | 探索：在院子里自由走地道，E 与村民、战友交谈，不响钟、敌军不动。按 B 进入警戒。警戒：人在树洞里朝东看敌军 |
| 2026-11-17 地道按记载修订 | 详见 `docs/TUNNEL_REDESIGN.md` 第九至十一节。树洞直道默认通到东屋内。翻口默认不挡这条直道。可走地面统一在 -3.8 米。墙根枪缝在地面暗堡上，不埋进主道顶的上方 |
