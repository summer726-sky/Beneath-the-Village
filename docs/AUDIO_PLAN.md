# 声音规划与审查

日期：2026-11-17  
范围：灰盒可玩闭环上的音效。不改胜负、敌军状态机、地图和 HUD 布局。

## 历史约束

声音为冀中平原村落、地道和步枪战，不做现代军旅、科幻或卡通音效。

已核对、本方案采用的史实（人民网对冉庄遗址与《斗争》记载的转述，以及课文《冀中的地道战》对联络方式的说明）：

- 报警主信号是村头老槐树上的钟。钟先响，人再吆喝。
- 地面传递敌情靠分段吆喝（史料里俗称“无线电”），地道里靠拉铃暗号（“有线电”）。本局没有拉铃玩法，不另造一套“几下铃代表什么”的假暗号。
- 地道内大声喊会暴露位置。玩家在地道里吆喝仍能喊，但声音压低、发闷。
- 冉庄使用过步枪、手榴弹和拉线雷一类地雷。枪声按单发步枪，拉雷按短促土制爆炸，不用连发枪、榴弹炮或能量武器。
- 不使用电影《地道战》台词（例如竹筒里的“各小组注意……”）。那些是后来的电影对白，不是本方案的口令。

本局口令按**现有工事**来写：北房夹壁、树下的钟、井下隔板。这是符合场景的功能性句子，不是某一次战斗的原始录音。

| 说话人 | 何时 | 玩家看见的字 | 声 |
| --- | --- | --- | --- |
| 村民 | 钟响之后 | 村民：有敌情！快往北房夹壁躲！ | 中文口语音。钟先响 |
| 村民 | 开始灌水 | 村民：鬼子在灌水，快去关隔板！ | 同上。与现有村民对白用词一致，只在这一句使用 |
| 玩家 | 警戒中按 G | 你喊：有敌情 / 进夹壁 / 小声 | 中文口语音 |
| 玩家 | 探索中按 G | 你低声说：先把地道走熟。钟在院子的树下。 | 压低 |
| 敌军 | 听到距离内变换口令 | 敌军（日语口令）：向前 / 射击 / 搜洞口 / 向井里灌水 | **不配中文语音**。字幕是日语口令的译文 |

日军口令留给以后的录音，不在字幕里假装已经说了日语：向前＝前へ，射击＝撃て，搜洞口＝穴を探せ，灌水＝井戸に水を入れろ。本局敌军没有分成日军和伪军，因此不让他们说民兵的中国话。

## 必有音效

| 设计要求 | 做法 |
| --- | --- |
| 警报钟 | 偏低的铜钟，连敲四下。只表示“报警”，不伪装成史料里的拉铃暗号 |
| 地面脚步 / 地道脚步 | 村民、战友、玩家：布鞋土地。敌军地面：硬底皮鞋。地道内：闷、短。玩家在地道里时，外面的声音也走闷声母线 |
| 枪声与地道回声 | 单发步枪。声源在地下或听者在地道时，经过低通和短混响 |
| 翻板 | 木板断裂。拉雷另是短促土炸，二者分开 |
| 隔板 | 木板滑落撞击 |
| 水 | 井口持续水流，音量随灌水进度升高；关上隔板后消退。灌满时有一次涌水 |
| 敌军喊话 | 听力范围内的中文译文。没有日语录音就不发声，避免配错语言 |
| 村民跑与躲 | 布鞋脚步；进藏身点时布料和土声，不叫喊惨叫 |
| 受击、空栓、交互 | 受击是闷击，不配惨叫。没有备弹，按射击或 R 只是空枪栓。取暗室弹药是布包，不是现代弹匣 |

关键信息仍走现有字幕。声音有距离衰减和左右方向。主音量用键盘 `-` / `=`，并写入 `user://audio_settings.cfg`。`AudioDirector.set_master`、`set_sfx`、`set_ambience` 留给以后的触屏滑条，本轮不加 HUD。

## 实现方式

- 新的自动加载 `AudioDirector` 只听 `EventBus`，并读取已经公开的位置、状态。不修改射击、胜负和 AI。
- 环境声和音效在运行时合成，打进内存波形。不从网上拉音频。Kenney 的 CC0 音效包可用作以后的脚步替换，但原包偏干净的工作室采样，且没有单发步枪和井水，这轮不打进包，避免卡通撞击声。
- 中文吆喝：若 `res://audio/voice/<id>.ogg` 存在，优先播放（正式录音放这里）。否则在 Windows 上用本机已有的“Microsoft Huihui”合成到 `user://voice_cache/`，不把这套声音提交进仓库。没有该声音或不是 Windows 时，只保留字幕。
- 慧慧是现代普通话女声，不是冀中方言，也不是史料原声。妇女自卫队、妇救会本来就负责传话，所以这套女声只覆盖村民和玩家吆喝。敌军、战友不使用它。战友原有字幕不动。

## 审查

审查标准：史实不编造、口令对得上本局工事、敌军语言不错配、不抄电影台词、不改玩法代码、离线、关键信息不只靠声音、地道和地面听得出来。

结论：**通过。** 可以按上表实现。

已知限制（不构成退回）：

- 中文音色是本机女声占位，听到的是正确的句子，不是当年的人。
- 日语口令这轮只有译文，听到的敌军存在感来自皮鞋和步枪。
- 移动端音量滑条尚未做，接口已留。
