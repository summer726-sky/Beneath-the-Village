# 声音规划与审查

日期：2026-11-17  
范围：灰盒可玩闭环上的音效。不改胜负、敌军状态机、地图和 HUD 布局。

## 历史约束

声音为冀中平原村落、地道和步枪战，不做现代军旅、科幻或卡通音效。

已核对、本方案采用的史实（人民网对冉庄遗址与《斗争》记载的转述，以及课文《冀中的地道战》对联络方式的说明）：

- 报警主信号是村头老槐树上的钟。钟先响，人再吆喝。
- 地面传递敌情靠分段吆喝（史料里俗称“无线电”），地道里靠拉铃暗号（“有线电”）。本局没有拉铃玩法，不另造一套“几下铃代表什么”的假暗号。
- 地道内大声喊会暴露位置。玩家在地道里吆喝仍能喊，但声音压低、发闷。
- 冉庄使用过步枪、手榴弹和拉线雷一类地雷。枪声按单发步枪，拉雷按短促土制爆炸，不用连发枪、榴弹炮或能量武器。
- 不使用电影《地道战》台词（例如竹筒里的“各小组注意……”）。那些是后来的电影对白，不是本方案的口令。

本局口令按**现有工事**来写：北房夹壁、树下的钟、井下隔板。这是符合场景的功能性句子，不是某一次战斗的原始录音。

| 说话人 | 何时 | 玩家看见的字 | 声 |
| --- | --- | --- | --- |
| 村民1 | 钟响之后，或开始灌水 | 村民：有敌情！快往北房夹壁躲！ / 鬼子在灌水，快去关隔板！ | 年纪较大的女声，偏低、偏慢 |
| 村民2 | 轮到她在地面传话时 | 同上两句 | 年轻女声，偏高、偏亮、偏快 |
| 村民3 | 轮到她在地面传话时 | 同上两句 | 另一个年轻女声，更低、更利落 |
| 玩家 | 警戒中按 G | 你喊：有敌情 / 进夹壁 / 小声 | 居中的男声，偏急 |
| 玩家 | 探索中按 G | 你低声说：先把地道走熟。钟在院子的树下。 | 同一男声，放慢 |
| 战友甲 | 接受命令 | 原有字幕：守这个孔 / 去关隔板 / 原地待命 | 更低、更暗的男声，不另加一行字幕 |
| 战友乙 | 接受命令 | 同上三句 | 年轻男声，更高、更快、更亮 |
| 敌军六人 | 听到距离内变换口令 | 敌军（日语口令）：向前 / 射击 / 搜洞口 / 向井里灌水 | 六个成年男声，音高和语速各不相同。字幕仍是译文 |

口令对上现有工事，不取电影《地道战》台词。日军说日语，不说民兵的中国话：向前＝前へ，射击＝撃て，搜洞口＝穴を探せ，灌水＝井戸に水を入れろ。六名日军各用一套音高和语速。本局敌军没有分成日军和伪军，小队按日军带队来配音。钟先响，再由还在地面上的那名村民吆喝。

## 必有音效

| 设计要求 | 做法 |
| --- | --- |
| 警报钟 | 偏低的铜钟，连敲四下。只表示“报警”，不伪装成史料里的拉铃暗号 |
| 地面脚步 / 地道脚步 | 村民、战友、玩家：布鞋土地。敌军地面：硬底皮鞋。地道内：闷、短。玩家在地道里时，外面的声音也走闷声母线 |
| 枪声与地道回声 | 单发步枪。声源在地下或听者在地道时，经过低通和短混响 |
| 翻板 | 木板断裂。拉雷另是短促土炸，二者分开 |
| 隔板 | 木板滑落撞击 |
| 水 | 井口持续水流，音量随灌水进度升高；关上隔板后消退。灌满时有一次涌水 |
| 敌军喊话 | 听力范围内播放日语口令，字幕仍是中文译文 |
| 村民跑与躲 | 布鞋脚步；进藏身点时布料和土声，不叫喊惨叫 |
| 受击、空栓、交互 | 受击是闷击，不配惨叫。没有备弹，按射击或 R 只是空枪栓。取暗室弹药是布包，不是现代弹匣 |

关键信息仍走现有字幕。声音有距离衰减和左右方向。主音量用键盘 `-` / `=`，并写入 `user://audio_settings.cfg`。`AudioDirector.set_master`、`set_sfx`、`set_ambience` 留给以后的触屏滑条，本轮不加 HUD。

## 实现方式

- 新的自动加载 `AudioDirector` 只听 `EventBus`，并读取已经公开的位置、状态。不修改射击、胜负和 AI。
- 环境声和音效在运行时合成，打进内存波形。不从网上拉音频。Kenney 的 CC0 音效包可用作以后的脚步替换，但原包偏干净的工作室采样，且没有单发步枪和井水，这轮不打进包，避免卡通撞击声。
- 角色配音放在 `res://audio/voice/<id>.wav`（也可换成同名 `.ogg`）。文件随包播放，运行时不再从网上拉音频。合成用的模型、词典和程序留在 `tools/_cache/`，不进仓库。来源和许可写在 `audio/voice/CREDITS.txt`。
- 玩家、战友甲、战友乙都从中文男声「超文」出发，再拉开音高和明暗：玩家居中，甲更低更暗，乙更高更快，听起来是年轻男声。
- 三名村民都从 Windows 慧慧出发：村民1更低更慢，是年纪较大的女声；村民2更高更亮，是年轻女声；村民3偏低但语速正常，是另一个年轻女声。谁还在地面上，就用谁的声音喊。只有本机没有这些文件时，Windows 才用慧慧补玩家和村民那几句。
- 六名日军用同一个 Open JTalk 成年男声，每人单独调音高和语速。没有对应文件时只留字幕，不用中文女声去读日语。
- 这些都是现代普通话或日语合成音，不是冀中方言，也不是史料原声。战友原有字幕不动，配音只跟在同一句口令上。

## 审查

审查标准：史实不编造、口令对得上本局工事、敌军语言不错配、不抄电影台词、不改玩法代码、离线、关键信息不只靠声音、地道和地面听得出来。

结论：**通过。** 可以按上表实现。

已知限制（不构成退回）：

- 中文男声是同一个「超文」拉开的三个人，中文女声是同一个慧慧拉开的三个人。年龄和明暗能分开，不是六个不同的录音演员。
- 日军六套音高来自同一个成年男声，分得开这六个人，不是六个不同的录音演员。
- 移动端音量滑条尚未做，接口已留。
