## 2. 可运行版本、启动方式与操作说明

### 环境

- Godot：`Godot_v4.7.2-stable_win64.exe`（winget：`GodotEngine.GodotEngine`）
- 项目目录：`D:\我的文件\11-项目仓库\地道战`

### 启动

```text
Godot 编辑器 → 导入/打开本目录 → 运行主场景 scenes/main/main.tscn
```

或命令行（将 GODOT 换为本机路径）：

```powershell
& $GODOT --path "D:\我的文件\11-项目仓库\地道战"
```

冒烟测试：

```powershell
& $GODOT --headless --path "D:\我的文件\11-项目仓库\地道战" -s res://tests/smoke_test.gd
```

### 操作

| 键 | 作用 |
|----|------|
| 空格 / 开始按钮 | 跳过开场，开始操作 |

## 5. 未解决问题、缺陷与风险

1. 交互依赖射线打到 `collision_layer=32` 的命中体；复杂角度可能偶发扫不到，需实机调距离。
2. 敌军无导航网格，可能在家具级障碍增多后卡步（当前灰盒障碍少）。
3. 胜负在击杀序列中可能先走「撤退胜利」而非「全歼」文案——规则允许，结算文案需让玩家读懂。
4. 截止 2026-11-19 19:00，P1 视觉与演示视频时间紧。
5. Aholo MCP **无余额查询接口**；API 连通已确认（`world_list` 成功），正式消费前需用控制台/其他渠道核对实余额。
