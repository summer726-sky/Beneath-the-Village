# 编制、难度与边界规则（2026-11-17）

本文件只审查和补规则，不改玩法代码。机关空间仍以 `docs/TUNNEL_REDESIGN.md` 第十一节和 `docs/MECHANISM_TACTICS.md` 为准。

## 历史对照

公开记载说的是整村地道：十字街四条干线、户户相连，来的常常是下乡搜索的小队到中队，不是四个人包下一座院子。本关只做一座院子，不能把一个班塞进同一口井。

| 设计 | 和记载的关系 |
|------|----------------|
| 翻板用棍支住，抽棍后两侧坠落，中间木轴可走 | 符合常见说法 |
| 岔口翻口改道，死道两侧枪眼 | 符合常见说法 |
| 翻眼把人和水隔开，水最终归井 | 种类符合。本关只有一层可走地面，隔板决定水去井池还是上主道，这是演示简化，不是记载里的上下两层 |
| 枪眼在墙根、门槛、洞口侧龛，一人位，露久了被还击 | 符合 |
| 洞窄，进洞的人把长枪留在洞口，一次只进一人 | 符合洞宽大约一人侧身 |
| 上方暗室跳到直道上 | 玩家要求保留。坡道进入，跳口落下，落点地板不拆。不是从院子地面挖的竖井 |
| 墙外树洞瞭望 | 来自手绘。记载里的古槐在村内十字街，挂钟、留枪眼，对应院子里的钟树 |
| 现在的 4 人 | 作为“进这一座院子的搜索组”偏少，也让树缝能在拉钟前把人打光 |
| 拉雷 | 只做北房支道一处。夹壁上房和毒气这轮不做 |

## 人数与难度

每人仍是一枪倒下。难度来自谁站在枪缝里、谁还没进村、全歼何时才算数，不来自加血。

4 人太容易。玩家在树洞里有 8 发子弹，敌人从东边走来，距离大约十多米，一枪一个人。四枪就能在拉钟之前结束战斗，翻板、翻口、灌水和村民隐蔽都用不上。

12 人接近一次下乡搜索的规模，但这座院子、8 发弹仓、一次只进一名步枪手的洞，盛不下。其余的人应理解为还在别的街道上，本关不把他们画出来。

**这一关用 6 人，难度是“紧的一小队”。**

| 谁 | 几人 | 侦察缝里能不能一开始打到 | 做什么 |
|----|------|--------------------------|--------|
| 尖兵步枪手 | 2 | 能 | 绕墙进院，搜索。同时只有一人进洞 |
| 工兵 | 1 | 能 | 不进洞。发现东屋、水井或驴槽之后，到水井倒水 |
| 分队长 | 1 | 第一枪之前能，第一枪之后离开缝的射界 | 不进洞。死亡且剩余少于 2 人才撤退 |
| 殿后步枪手 | 1 | 不能。停在墙东北，树缝打不着 | 树洞一暴露就对树缝还击，钟响后才进院 |
| 后进步枪手 | 1 | 不能。钟响或尖兵有人倒下才从墙南入画 | 进院搜索，不和别人同时下洞 |

6 人用掉 6 发，弹仓还剩 2 发。要打完必须进地道补弹，或者用翻板、枪眼省子弹。工兵和分队长不进洞，所以翻板打的是步枪手，不是把编制里的每个人都送进陷阱。

## 侦察时把人打光

现在的规则会直接判全歼胜利。这和“先预警、再保护村民”相反，也不符合搜索组进村之后才展开地道战的过程。

侦察时可以开枪，把当时场上的敌军全部打倒，算全歼胜利。代价是第一枪就暴露树缝：听得见的敌军立刻对树缝加快射击，并沿进村路线加速。开战之后没有士气撤退，也不因分队长阵亡收兵。地面上的火力比地道里更密，人要进地道再用枪眼、跳口、翻板和拉雷。胜利只有全歼。两名村民已被抓，或指挥室已经灌满，失败优先。

探索模式里敌军不动，开枪不造成伤害，也不结算。

## 其他边界

| 情况 | 规则 |
|------|------|
| 只打死工兵 | 湿痕停下。搜索和进洞继续，不因此胜利 |
| 只打死分队长 | 不结束战斗。其余的人继续搜查，步枪手仍会进洞 |
| 钟响后才全歼 | 合法胜利，除非此时已经有两名村民被抓或指挥室已灌满 |
| 翻板 | 人已经踩在木轴上再抽棍，砸不到。直道上没有翻板 |
| 隔板 | 指挥室还没铺满时关上，湿痕停住。已经铺满，再关也是灌水失败 |
| 洞里超过约 40 秒仍没找到人 | 进洞的步枪手退回洞口，不因此判玩家胜利 |
| 玩家在探索模式里走到树洞开枪 | 视为没打中，敌军人数不变 |
